## Shutter shop questions (ask 2–3 shops)
- Do you make perforated / "vented" slats, and can only the top ~12 slats be perforated?
- Price per m² plain vs perforated, same gauge (ask for gauge 24 or thicker)
- Size quoted as 3.00 m CLEAR between guides × height to beam
- Does the curtain still roll into the same drum size? (perforated slats are the same profile, so it should)
- Optional: insect mesh behind the perforated band (from inside, removable)
